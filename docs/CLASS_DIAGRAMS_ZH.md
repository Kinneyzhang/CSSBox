## 数据流图

### 完整渲染流程

```
┌─────────┐
│ URL/HTML│
└────┬────┘
     │
     ▼
┌─────────────────┐
│DocumentSource   │ 加载文档内容
│ - load()        │
└────┬────────────┘
     │
     ▼
┌─────────────────┐
│  DOMSource      │ 解析HTML
│ - parse()       │ 使用 NekoHTML
└────┬────────────┘
     │
     ▼
┌─────────────────┐
│ DOM Document    │ DOM 树
└────┬────────────┘
     │
     ▼
┌─────────────────┐
│  DOMAnalyzer    │ 应用CSS样式
│ - getStyleSheet │ 加载外部CSS
│ - getStyle()    │ 计算元素样式
└────┬────────────┘
     │
     ▼
┌─────────────────┐
│  BoxFactory     │ 创建盒子树
│ - createBox()   │ 为每个DOM节点创建Box
└────┬────────────┘
     │
     ▼
┌─────────────────┐
│   Box Tree      │ 盒子树结构
└────┬────────────┘
     │
     ▼
┌─────────────────┐
│    Engine       │ 布局计算
│ - createLayout()│ 计算位置和尺寸
└────┬────────────┘
     │
     ▼
┌─────────────────┐
│   Viewport      │ 根盒子
│ - layout()      │ 递归布局子元素
└────┬────────────┘
     │
     ▼
┌─────────────────┐
│ Renderer        │ 渲染
│ - render()      │ 遍历盒子树
└────┬────────────┘
     │
     ▼
┌─────────────────┐
│BufferedImage /  │ 输出
│ JPanel Display  │
└─────────────────┘
```

### CSS 样式计算流程

```
┌───────────┐
│ CSS Rules │ (外部CSS + 内部CSS + 内联样式)
└─────┬─────┘
      │
      ▼
┌───────────────┐
│ 选择器匹配     │ 为每个元素查找匹配的规则
└───────┬───────┘
        │
        ▼
┌───────────────┐
│ 层叠计算       │ 按优先级排序（来源、特异性、顺序）
└───────┬───────┘
        │
        ▼
┌───────────────┐
│ 继承处理       │ 继承父元素的可继承属性
└───────┬───────┘
        │
        ▼
┌───────────────┐
│ 值计算         │ 将相对值转换为绝对值
└───────┬───────┘
        │
        ▼
┌───────────────┐
│ ComputedStyle │ 最终计算样式
└───────────────┘
```

### 布局计算流程

```
┌────────────┐
│ Box Tree   │
└──────┬─────┘
       │
       ▼
┌──────────────────┐
│ 确定盒子类型      │ (block, inline, inline-block, table, ...)
└─────┬────────────┘
      │
      ├─── block ──────▶ ┌──────────────────┐
      │                  │ 块级布局          │
      │                  │ - 计算宽度        │
      │                  │ - 垂直堆叠子元素  │
      │                  │ - 计算高度        │
      │                  └──────────────────┘
      │
      ├─── inline ─────▶ ┌──────────────────┐
      │                  │ 内联布局          │
      │                  │ - 创建行框        │
      │                  │ - 文本换行        │
      │                  │ - 基线对齐        │
      │                  └──────────────────┘
      │
      ├─── float ──────▶ ┌──────────────────┐
      │                  │ 浮动处理          │
      │                  │ - 脱离正常流      │
      │                  │ - 左/右浮动       │
      │                  └──────────────────┘
      │
      └─── absolute ───▶ ┌──────────────────┐
                         │ 绝对定位          │
                         │ - 相对包含块定位  │
                         └──────────────────┘
```
